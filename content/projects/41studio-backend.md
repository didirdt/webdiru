Two years at **41Studio** in Cimahi, starting on the backend side of web
projects for business clients — mostly internal tools and client-facing
sites.

### What I built

- **Ruby on Rails applications** with REST APIs consumed by web and mobile
  clients.
- **Background processing** with Sidekiq and Redis — report generation, email
  dispatch, and scheduled jobs moved off the request cycle.
- **CodeIgniter applications** where a client already had PHP hosting and
  changing the stack would have cost more than it saved.
- **Database schemas and DFDs** before implementation, which was how the
  studio agreed on scope.

### Working across stacks early

PHP and Rails in the same year is a good way to learn that the language isn't
the hard part. The hard part is the same in both: modelling the data
correctly, keeping the boundary between business logic and the framework
clean, and writing migrations you can roll back.

### Stack

Ruby on Rails · PHP · CodeIgniter · PostgreSQL · MySQL · Sidekiq · Redis
